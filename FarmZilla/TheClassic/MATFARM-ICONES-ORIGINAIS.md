# Imagens originais dos 49 materiais do Mat Farm

O FarmZilla The Classic pode exibir os sprites originais do Rody's Elements Editor enviados pelo usuario.

1. Baixe o pacote `MatFarm-Icones-Originais-49.zip` entregue nesta conversa.
2. Extraia a pasta `MatFarmIcons` **ao lado de `FarmZilla-Classic.exe`** (na mesma pasta do executavel).
3. Conecte o personagem, abra Mat Farm; o log `aplicativo.log` registra `Icones originais Rody: 49/49` quando todos os arquivos estao presentes.

A correspondencia entre template ID e numero do JPG fica em `FarmZilla-Classic/RotaOriginalMaterialIcons.cs`. Ela foi obtida da tabela do Rody's mostrada pelo usuario e cruzada com os 49 materiais do catalogo. Os IDs numéricos dos JPGs nao sao os IDs de item do elements.data.

Sem os arquivos auxiliares, a funcionalidade continua usando a leitura anterior de texturas do `surfaces.pck`; sem imagens falsas.
